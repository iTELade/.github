# iTELade organization profile

This repository contains the public GitHub organization profile and shared organization metadata.

The profile shown at [github.com/iTELade](https://github.com/iTELade) is maintained in [`profile/README.md`](profile/README.md).

## Repository policy

This repository contains public presentation and community metadata only. Infrastructure credentials, private configuration, internal documentation and secrets must not be committed here.

Changes to protected content should be reviewed before merging.
